# Soundeffekte

Die Komposition nutzt sieben Effekte aus der HyperFrames-Mediathek (Quelle: [Pixabay](https://pixabay.com/sound-effects/),
[Pixabay Content License](https://pixabay.com/service/license-summary/)):
`chime`, `click-soft`, `ping`, `pop`, `sparkle`, `whoosh`, `whoosh-short`.

Sie sind nicht eingecheckt, weil die Lizenz die Weitergabe unveränderter Dateien nicht erlaubt.
`npm run sfx` (läuft automatisch vor `dev`, `check` und `render`) kopiert sie aus dem installierten
HyperFrames-Skill `media-use` hierher.
